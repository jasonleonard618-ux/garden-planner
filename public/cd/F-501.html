GENERAL NOTES

  1. Gate swings into the garden, hinges on the garden side. (practical choice)
  2. Set posts plumb and parallel and fix the header before hanging the gate.
  3. Hang the gate only after the post concrete has cured per the bag's instructions. (packet guidance)
  4. Leave 1/2" at the hinge and latch side and 1" above the sill so the gate clears when wood swells. (practical choice)
  5. Hardware specs are suggestions. Check each maker's load rating against the gate weight before you buy.
  6. Fasteners touching pressure-treated wood: hot-dip galvanized or stainless. Source: IRC R317.3.1

KEYNOTES

  1. 14×4 cedar gate post, 12' long, set in concrete; see F-104 detail 6.
  2. 2Doubled 2×8 cedar header, one each face, top at 7'-6"; ties the gate posts so they stay parallel. (practical choice)
